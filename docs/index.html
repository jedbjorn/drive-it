A small, inspectable bridge

Start with the Revit you already have open.

Drive It works with the Revit home screen or an open model. The current main branch reads session metadata; modeling operations are not yet part of this early release.

01

Choose a process

Pass the Windows process ID for the Revit instance your client should query.

02

Read the session

The add-in returns the process ID, Revit version, and build as structured MCP output.

03

Stay on your workstation

The server uses stdio and a named pipe restricted to the current Windows user.

How it works

Four local pieces. One clear path.

  1. MCP clientLaunches the server over stdio
  2. Node.js serverRegisters the session tool
  3. Named pipeConnects to the selected process
  4. Revit add-inReturns its session snapshot

Build and install

Two dependencies. Two build commands.

Install Node.js 22 or newer and the .NET 8 SDK, then run these commands in PowerShell with Revit closed. Revit API references resolve from NuGet.

npm ci
dotnet build src/DriveIt.Revit -c Release
