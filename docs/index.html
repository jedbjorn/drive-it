See it. Stop it. Undo it.

You can see what the agent is doing, and what it did.

An agent that changes your model should not be a black box. Drive-It names every script, keeps a record of every run, and puts back what a failed run changed.

Install

One installer. No admin rights.

The MSI installs for your Windows user and brings what Drive-It needs with it. It registers Drive-It with the Claude, ChatGPT and Codex apps it finds, and changes nothing else in their settings.

  1. 1

    Run the installer

    Download the MSI and run it. If Windows SmartScreen asks first, choose More info, then Run anyway.

  2. 2

    Start Revit

    Revit 2026 or 2027 asks about the Drive-It add-in the first time. Choose Always Load.

  3. 3

    Your workspace is ready

    Scripts work in C:\DriveIt\default. To use another folder, open Drive-It from the Start Menu or Revit's Add-Ins tab.

  4. 4

    Restart your agent app

    Claude, ChatGPT or Codex picks up Drive-It when it restarts. Then ask it for something in Revit.

The Drive-It window

You stay in charge.

One small window holds the settings and the record. Open it from the Start Menu, or from the Add-Ins tab in Revit.

  • Choose the folder scripts may read and change
  • Set how long one script may run, from 10 to 600 seconds
  • Approve or deny a script that asks to reach outside the folder
  • Read the receipt of any run, including the ones that failed

Early, and plain about it

What to know before you start.

Drive-It is in early development. It needs Windows and Autodesk Revit 2026 or 2027, and it is tested with Claude Opus 5.5 on High thinking. Its rules limit what a script can reach, but they are a guardrail, not a sandbox: use it with an agent and prompts you trust.
