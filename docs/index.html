A small, inspectable bridge

Start with the Revit you already have open.

Drive It works with the Revit home screen or an open model. The alpha has three MCP tools: one reads the session, one runs a script through typed document and model operations, and one returns the API reference.

01

Choose a process

Pass the Windows process ID for the Revit instance your client should query.

02

Read the session

The add-in returns the process ID, Revit version, and build as structured MCP output.

03

Run a script

Scripts work inside the workspace folder you choose, ask before reaching outside it, and leave a receipt of each run.

How it works

Four local pieces. One clear path.

  1. MCP clientLaunches the server over stdio
  2. Node.js serverRegisters the MCP tools
  3. Named pipeConnects to the selected process
  4. Revit add-inRuns each request inside Revit

Install

One installer. No admin rights.

Download the alpha MSI from the releases page and run it. It installs for your Windows user and registers Drive It with Claude Desktop, Claude Code, and Codex where it finds them. The alpha is not code-signed yet, so Windows SmartScreen will ask first. To build from source instead, install Node.js 22 or newer and the .NET 8 SDK, then run the commands shown here.
